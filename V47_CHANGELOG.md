# V47

- New unified CSS/React splash for every case family: Rifle, Sniper, Pistol, Knife, Gloves Arsenal plus classic/specialist cases.
- Legacy Arsenal splash components and assets removed from runtime imports.
- Case preview opens immediately on click and has a dedicated `VOIR LES DROPS` button; server preview provides exact per-item probabilities.
- Five wear conditions: Mauvais état, État moyen, État correct, Bon état, Comme neuf; condition changes effective value and resale value.
- Inventory, market, selling and upgrades respect the rolled condition; upgrade history remains attached to the inventory row.
- Beginner Case rewards have been softened to make strong drops much rarer.
- Upgrade target selection uses the source item's effective condition-adjusted value.
