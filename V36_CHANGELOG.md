# WellCase V36

- Replaced the three Arsenal case splash images with clean case-focused crops derived from the live case assets, removing the previous embedded splash artwork and label mismatch.
- Arsenal splash resolver now points to the clean Rifle/Knife/Gloves splash assets by exact case name and aliases.
- Upgrade UI palette softened from fluorescent green to a premium muted jade/emerald gradient.
- Upgrade chance color remains dynamic: red for low chance, amber for medium, muted green/jade for high chance.
- Case drop weighting is now price-aware inside each rarity tier: more expensive cases bias toward higher-value drops while preserving the hard cap on the rarest tier.
- Highest rarity remains approximately 0.15% to 0.50% depending on case price.
