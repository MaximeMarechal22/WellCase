# WellCase V26

- Daily quest `upgrade_2` now counts only successful upgrades and displays the correct objective.
- Added five weapon-specialist cases synchronized from the live catalog: Pistol, Assault Rifle, Sniper, Knife, Gloves.
- Specialist cases are priced by category and use rarity/value-weighted probabilities so expensive categories are naturally harder and more expensive.
- Specialist case images added under `frontend/public/images/cases/type_*.png`.
- Collections are now clickable and show every item in the selected category with owned/missing state, rarity, image and value.
- Collection backend now returns item details for each category.
